# НТО 26/27 — «Цифровая археология»

Решение задачи **D. «Цифровая археология»** первого этапа НТО 26/27 по профилю **«Технологии беспроводной связи»**.

## Идея

В архиве находятся журналы работы экземпляров старого HTTP key-value хранилища. Для каждого журнала нужно восстановить состояние хранилища и проверить, соответствует ли каждый записанный ответ протоколу.

Используется словарь Python:

```python
store = {}
```

Он хранит пары `ключ -> данные`.

Проверяются основные операции:

- `GET` — возвращает сохранённые данные или `404`;
- `POST` — сохраняет данные, возвращает их и `X-Length`;
- `DELETE` — удаляет данные и проверяет `X-Checksum` как XOR всех байтов;
- `SHOW` — проверяет ответ по заголовку `Thing`.

Тела сообщений читаются как `bytes`, поскольку в архиве могут встречаться произвольные бинарные данные.

## Запуск

Положить рядом с `solution.py` архив:

```text
 twc12_http_archive.zip
```

Запустить:

```bash
python solution.py
```

Программа проверяет все `.bin`-журналы внутри архива и выводит процент полностью корректных журналов.
